🌱 # Grow Guide - Crop Recommendation System

Welcome to Grow Guide, an innovative web application designed to empower farmers and agricultural enthusiasts with intelligent crop recommendations. This system leverages the power of machine learning to analyze various environmental and soil conditions, providing data-driven suggestions for optimal crop cultivation.

Our goal is to assist users in making informed decisions that can lead to increased yields and sustainable farming practices.

## ✨ Features

*   ** Inteligente Crop Recommendations**: Utilizes a pre-trained machine learning model to provide accurate crop suggestions, taking into account crucial factors like soil nutrients, pH levels, rainfall, and temperature.
*   **🖥️ User-Friendly Interface**: A responsive and intuitive web-based interface allows users to easily input their specific conditions and instantly receive personalized crop recommendations.
*   **📊 Data Analysis**: Includes comprehensive tools and Jupyter notebooks for in-depth understanding and exploration of crop-related data, aiding in agricultural research and insights.
*   **🚀 Scalable ML Logic**: Designed with modular and maintainable machine learning components, ensuring easy updates, improvements, and scalability for future enhancements.

### Webpage Features

Our web interface is built using Flask and Jinja2 templating, offering several key pages:

*   **`index.html` (Homepage)**: The main landing page of the application, serving as an introduction to Grow Guide and its purpose.
*   **`predict.html` (Prediction Page)**: This dedicated page allows users to input their environmental and soil data (e.g., Nitrogen, Phosphorus, Potassium, pH, temperature, humidity, rainfall) through an interactive form. Upon submission, it displays the tailored crop recommendations generated by the machine learning model.
*   **`analysis.html` (Analysis Page)**: Potentially designed to display data visualizations, statistical analysis results, or in-depth reports related to crop data and agricultural trends, offering valuable insights to users.
*   **`about.html` (About Page)**: Provides detailed information about the Grow Guide project, its objectives, the technologies used in its development, and information about the creators or contributors.
*   **`base.html` (Base Template)**: A fundamental base template that establishes the common structure, header, footer, and navigation for all other HTML pages, ensuring a consistent user experience and reducing code duplication.

## 📁 Key Components:

*   **`app.py`**: 🌐 The heart of the Flask application, responsible for defining URL routes, handling incoming HTTP requests, seamlessly integrating with the machine learning backend, and dynamically rendering HTML templates to present information to the user.
*   **`dataset/`**: 🗃️ This critical directory stores both raw and preprocessed datasets essential for training and validating the machine learning model. It includes:
    *   `crop_feasable_conditions.csv`: 📄 A dataset likely containing a curated list of feasible growing conditions for various crops, used for reference or specific analyses.
    *   `Crop_recommendation.xls`: 📊 The primary and most comprehensive dataset utilized for training the crop recommendation machine learning model, containing a wide range of features and target crop labels.
*   **`ml_logic/`**: 🧠 This package encapsulates all machine learning-related functionalities, ensuring a clear separation of concerns.
    *   `predict.py`: 🔮 Contains the core logic for loading the serialized machine learning model and executing predictions based on the input features provided by the user.
    *   `crop_data.py`: ⚙️ Dedicated to handling various aspects of crop data, including preprocessing raw data, performing feature engineering, and efficiently loading datasets for model training and prediction.
    *   `chat.py`: 💬 Potentially implements an interactive chatbot feature, allowing users to converse with the system for input or to retrieve information, or an interface for conversational data input.
    *   `api.env`: 🔑 A file to store environment variables, API keys, and other sensitive configuration parameters securely, crucial for the application's operation in different environments.
*   **`pickle/`**: 📦 This directory serves as the storage location for serialized machine learning artifacts, enabling quick loading of pre-trained models.
    *   `model.pkl`: 🤖 The pre-trained machine learning model, serialized using Python's `pickle` module, ready for deployment and inference.
    *   `scaler.pkl`: ⚖️ A serialized data scaler (e.g., StandardScaler, MinMaxScaler) used to transform new input features to the same scale as the data on which the model was trained, preventing data leakage and ensuring consistent performance.
*   **`requirements.txt`**: 📜 This file lists all external Python dependencies and their exact versions required for the project. It ensures that anyone setting up the project can install the necessary libraries to run the application consistently.
*   **`SRCNOTEBOOK.ipynb`**: 📓 A Jupyter notebook that acts as a comprehensive workspace for data exploration, initial model training, rigorous evaluation of model performance, and various machine learning experiments.
*   **`static/`**: 🖼️ This directory contains all static web assets that are served directly by the Flask application to the client-side browser.
    *   `js/predict.js`: 💡 JavaScript code specifically designed to enhance the interactivity and user experience of the prediction interface, handling client-side logic and dynamic content updates.
    *   `style.css`: 🎨 Cascading Style Sheets that define the visual presentation of the web application, ensuring a modern, aesthetically pleasing, and responsive design across different devices.
    *   `src/hero.png`: 🏞️ An image asset, most likely used as a prominent hero image or banner in the application's user interface to create an engaging first impression.
*   **`templates/`**: 📃 This directory holds all the HTML templates that the Flask application renders to construct the dynamic user interface.
    *   `index.html`: 🏠 The main landing page or homepage of the application, serving as the entry point for users.
    *   `predict.html`: 📈 The dedicated page where users can input their environmental and soil data to receive tailored crop recommendations.
    *   `analysis.html`: 🔍 A page potentially designed to display data visualizations, statistical analysis results, or in-depth reports related to crop data and agricultural trends.
    *   `about.html`: ℹ️ Provides detailed information about the project, its objectives, the technologies used, and the team or individuals involved in its development.
    *   `base.html`: 🧱 A fundamental base template that establishes the common structure, header, footer, and navigation for other HTML pages, promoting consistency and reducing code duplication.

## Installation

To set up the project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/Grow-Guide.git
    cd Grow-Guide
    ```
2.  **Create and activate a virtual environment:**
    ```bash
    python -m venv venv
    # On Windows
    .\venv\Scripts\activate
    # On macOS/Linux
    source venv/bin/activate
    ```
3.  **Install the required dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
4.  **Set up environment variables:**
    Create an `api.env` file in the `ml_logic` directory based on your specific needs. This file should contain any API keys or configuration settings required by the application.

## Usage

To run the Flask application:

1.  **Activate your virtual environment** (if not already active).
2.  **Run the Flask application:**
    ```bash
    python app.py
    ```
3.  Open your web browser and navigate to `http://127.0.0.1:5000/` (or the address shown in your terminal). You can then interact with the crop recommendation system through the web interface.
